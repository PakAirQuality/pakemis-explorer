# Ask PakEmis development evaluation: the 53 cases (12 November 2026)

What each case asks, what a right answer looks like, what the scorer checks, and how the agent did
on 12 November 2026. The cases themselves live in `eval/cases/dev.yaml` (with their truth requests);
their reference figures are computed by `eval/resolve_references.py` into `dev.resolved.json`. This
file is a readable record of one run, not the source of truth.

## The run

- Model: gemini-3.1-pro-preview, through the real app in-process (`eval/run_baseline.py`).
- Turn limit: 50 seconds, as in production (`PAKEMIS_ASK_TURN_SECONDS=50`).
- Query core: the vendored engine with patch 0002 (`PAKEMIS_QUERY_PATH=api/vendor`).
- Code under test: the November 2026 changes (activity results sent as tables, `add_up` and
  `calculate`, checked charts, the bare-number gate off, rewritten prompt rules 1, 2, 7 and 12, a
  combined Pakistan figure with each province's date, fiscal years matching their months).
- The app's daily token budget was raised for the eval process (`PAKEMIS_ASK_DAILY_TOKENS`): at the
  default 3 million a full run stops at about D28.
- Cost: about $5.85 in all (two halves plus one repeat of D17).
- Scorecards: `eval/results/scorecard_nov12-full-a-rescore_dev.json` (D01-D27),
  `scorecard_nov12-full-b-rescore_dev.json` (D28-D53), `scorecard_nov12-d17_dev.json` (D17 again);
  transcripts beside them.

## How the scorer reads an answer (changed 12 November 2026)

Since the agent writes its own figures, `eval/lib/score.py` now:

- reads "401.09 million tonnes" both as 401,090,000 and as 401.09 (a reference held in Mt);
- reads a chart's figures from its data;
- does not count years and fiscal years ("2023-24") as figures where a case forbids any figure;
- accepts `scales` (a figure held in "thousand" units), `must_chart` and `must_visual` in a case.

D14 changed meaning: until November 2026 the AR5-minus-AR6 difference was forbidden (the agent could
do no arithmetic); it now must be given, computed by `calculate`.
